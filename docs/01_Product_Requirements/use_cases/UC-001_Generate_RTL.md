# UC-001 Generate RTL

## Goal

Generate synthesizable SystemVerilog RTL from a structured hardware specification.

## Primary Actor

RTL Engineer

## Preconditions

- Project exists
- Hardware specification is available
- Target language is selected

## Main Flow

1. Engineer submits specification.
2. AI analyzes requirements.
3. AI retrieves relevant engineering knowledge.
4. AI generates RTL.
5. AI performs self-review.
6. Engineer reviews the RTL.
7. RTL is committed to the project.

## Alternate Flows

- Specification is incomplete.
- AI requests clarification.
- Engineer edits generated RTL.

## Postconditions

- RTL artifact is stored.
- Review history is preserved.
- Traceability links are created.

- F-201 RTL Generation
- F-202 RTL Review
